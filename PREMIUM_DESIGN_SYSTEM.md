# Premium Design System Instructions
# AI Focus Guard / Short Block Extension

You have access to these skills:
- Framer Motion skills (`framer-motion-*`) → gestures, layout animations, scroll, variants, React
- UI/UX Pro Max (`ui-ux-pro-max`) → design intelligence, color systems, UX guidelines, hierarchy
- MotionSites Web Builder → building polished interactive web experiences

Your mission is to make the entire extension look **cinematic, clean, premium, classic, luxurious, friendly, and trustworthy**.

Use the skills above to achieve every Core Concept listed below.

---

### 1. Visual Hierarchy
- Use UI/UX Pro Max to establish clear hierarchy on every screen.
- Main headings & important numbers (timer, stats, big numbers) → **Melodrama**
- Body text, labels, secondary information → **Stardom**
- Create strong size, weight, and color contrast so the eye always knows what is most important first.

### 2. Color Psychology & Hierarchy
Primary action color: **Light Pink** (from the provided palette)

Full palette direction:
- Deep Burgundy / Near Black → Authority, depth, focus, dark backgrounds
- Mid Reds → Energy and urgency (use sparingly)
- Light Pink → Primary actions, highlights, active states, important numbers
- Soft Pink → Hover states and secondary accents
- White / Off-white → Clarity, breathing space, light mode backgrounds

Support both **Dark Mode** and **Light Mode**.
Use UI/UX Pro Max to generate balanced, accessible color tokens for both themes.

### 3. Cinematic Atmosphere
- Create depth using soft gradients, subtle shadows, and layered surfaces.
- Prefer restrained, elegant layouts over busy ones.
- Use generous spacing and breathing room (luxury through restraint).
- Avoid harsh borders. Prefer soft separation and elevation.

### 4. Emotional Consistency
- Personality: Neutral, calm, disciplined, gently supportive, slightly luxurious.
- Every element (color, type, motion, microcopy) must feel like it belongs to the same brand.
- Tone should feel trustworthy and quietly powerful — never loud or childish.

### 5. Micro-interactions & Motion (Critical)
Use Framer Motion skills heavily:
- Smooth hover animations on buttons, cards, and interactive elements
- Elegant scroll-triggered animations
- Layout animations when content appears or changes
- Soft scale, fade, and slide transitions
- Timer and progress elements should feel alive but not distracting

Motion principles:
- Duration: 0.25s – 0.5s for most interactions
- Easing: ease-out or soft custom cubic-bezier
- Avoid aggressive, bouncy, or playful motion — keep it premium and controlled

### 6. Trust & Addictive Quality
- Clear visual feedback on every action
- Calm, confident states (never chaotic)
- Subtle rewarding micro-animations when the user completes focus sessions or blocks shorts
- Make returning to the extension feel pleasant and slightly rewarding

### 7. Logo & Identity
- Design a simple, memorable logo / wordmark that works in both dark and light modes.
- The logo should feel cinematic, clean, and premium.
- Prefer Melodrama or a refined combination with the color system.
- Logo must look good at small sizes (extension icon) and larger sizes.

---

### How to Use Your Skills

| Goal                          | Skill to use                  | What to do |
|------------------------------|-------------------------------|----------|
| Color system & hierarchy     | UI/UX Pro Max                | Generate tokens, contrast rules, dark/light themes |
| Premium layout & spacing     | UI/UX Pro Max                | Apply luxury spacing and visual hierarchy |
| Hover, scroll, transitions   | Framer Motion skills         | Implement smooth, cinematic micro-interactions |
| Page transitions & layout    | Framer Motion + MotionSites  | Create fluid, high-end page and component animations |
| Overall polish               | All three together           | Combine design intelligence + motion |

---

### Rules
- Never make it look generic or “AI-generated”.
- Prefer restraint and elegance over decoration.
- Every animation must feel intentional and premium.
- Maintain the same identity across Popup, Research page, History page, and Chatbot.
- Both dark and light modes are required.
- Fonts: Melodrama (headings + important numbers), Stardom (body & UI text). Since font files are not available, use the best available similar high-quality alternatives or load them properly if possible.

Apply these instructions on every screen and component you touch.
