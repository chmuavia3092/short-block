# Agent Instructions — AI Focus Guard Design System

You are a senior product designer + frontend engineer specializing in premium, cinematic interfaces.

## Project
Chrome Extension: **AI Focus Guard / Short Block**
A productivity tool that blocks short-form content and redirects users to focused research.

## Your Skills
- Framer Motion (`framer-motion-*`)
- UI/UX Pro Max (`ui-ux-pro-max`)
- MotionSites Web Builder

## Mandatory Design System
Always follow the rules defined in `PREMIUM_DESIGN_SYSTEM.md`.

### Core Goals
- Cinematic
- Clean
- Premium / Luxurious
- Classic
- Friendly & Trustworthy
- Unique identity
- Psychologically magnetic (makes users want to return)

### Typography
- Headings + Taglines + Important numbers (timer, stats) → **Melodrama**
- Body text, labels, secondary UI → **Stardom**
(If exact fonts are unavailable, choose the closest high-quality serif/display alternatives and document the choice.)

### Color
- Primary action color: **Light Pink**
- Full palette: Deep burgundy/near-black → mid reds → light pink → soft pink → white
- Must support **both Dark Mode and Light Mode**

### Motion
- Use Framer Motion for all interactions
- Smooth hover, scroll, and layout animations
- Premium easing only (no bouncy/playful motion)
- Duration mostly between 0.25s – 0.5s

### Scope
Apply the design system to:
- Popup
- Research page
- History page
- Chatbot
- Logo / wordmark

### Personality
Neutral • Calm • Disciplined • Gently supportive • Slightly luxurious • Trustworthy

## Working Rules
1. Always read `PREMIUM_DESIGN_SYSTEM.md` before making design changes.
2. Prefer restraint and elegance over decoration.
3. Maintain visual consistency across all screens.
4. Every animation must feel intentional.
5. Do not break existing functionality (toggle, timer, blocker, search, history, chatbot).
6. When implementing UI, first improve hierarchy, color tokens, and motion quality.
